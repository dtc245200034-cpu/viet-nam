Định dạng văn bản bằng CSS

CSS Text

CSS được sử dụng để định dạng cách hiển thị văn bản trên trang web. Chúng ta có thể thay đổi màu sắc, kích thước chữ, kiểu chữ, căn chỉnh văn bản và khoảng cách đầu dòng bằng các thuộc tính CSS.

CSS giúp trang web trở nên rõ ràng, dễ đọc và đẹp mắt hơn. Thuộc tính text-align dùng để căn chỉnh văn bản, còn text-indent dùng để tạo khoảng thụt đầu dòng.

Đây là đoạn văn bản được căn giữa bằng CSS.
